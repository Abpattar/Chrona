# File Pack Manifest

This pack is an architecture and implementation-instructions deliverable, not a completed app. It contains:
- Source-of-truth requirements and master prompt (original PDFs preserved under `source-references/`).
- Product requirements, architecture, schema/interfaces, shared contracts and symbol registry.
- Dependency map, file responsibility map, target repository directory tree, decision register and change control.
- Toolchain/OS guidance, visual specification, risk register, privacy/security approach, test and acceptance criteria.
- URE evaluation plan and open items.
- A master OpenCode execution prompt and eight sequential phase prompts.
- Resume/progress and final-verification templates.

## Boundary

No Android application source code, APK, release artifact, backend, database instance or executed device test is included. Those belong to the implementation phase.
