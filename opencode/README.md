# OpenCode execution pack

Use `OPENCODE_MASTER_EXECUTION_PROMPT.md` once at the start of the implementation session. Execute `phase-prompts/PHASE_01_FOUNDATION.md` through `PHASE_08_URE_EVALUATION_AND_FINAL_RELEASE.md` sequentially in the same repository and same agent context. Do not run phase prompts as independent projects.

Before every phase, inspect the actual repository and `PROGRESS.md`. Each phase ends with tests/evidence, a progress update, and a gate. A failed gate does not become passed merely because the prompt sequence expects to continue.
